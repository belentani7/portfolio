# BELENTANI7 — GitHub Portfolio

Índice vivo de los proyectos públicos de [belentani7](https://github.com/belentani7):
búsqueda, filtro por categoría y orden (nombre, estrellas, actualización).
Los datos se leen en directo desde la API pública de GitHub; sin build, sin dependencias.

## Uso

Abre `index.html` en cualquier navegador o sírvelo como estático
(GitHub Pages, Vercel, Netlify).

## Origen

Generado a partir de `preview.html` y reparado: descripciones curadas
validadas contra la API (solo repos públicos existentes, sin duplicados),
enlaces endurecidos (`rel="noopener"`, URLs escapadas y validadas).
